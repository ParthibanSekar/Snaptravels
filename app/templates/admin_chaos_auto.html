How Continuous Auto Chaos Works
Click to expand

Continuous Loop: Auto Chaos cycles through all 5 chaos types in a random order. After the last type in a cycle finishes and cools down, a new cycle begins with a freshly shuffled order. This runs 24/7 until you disable it.

Event Duration: Each chaos event runs for 30 or 60 minutes (randomly chosen).

Cooling Gap: A mandatory 3-hour gap (plus 0–30 min random jitter) separates each event. This gives APM time to show recovery before the next chaos begins.

Daily Reshuffle: At 05:35 IST (00:05 UTC) each day, the entire schedule is rebuilt from scratch with new random ordering and timing.

5 Chaos Types: Named Outage Profiles (DB down, payment gateway, etc.), Page Load Performance (delays, JS errors, resource failures), Functionality Failures (broken search, forms, CTAs), Component-Level Chaos (UI breakage), and A/B Test Chaos (DOM identifier mutation).
