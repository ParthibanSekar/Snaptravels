How Chaos Engineering Works

The Chaos Control Panel injects realistic, controlled failures into SnapTravels so that monitoring tools (Synthetic, APM, RUM, and Mobile APM) detect and alert on them — perfect for RCA demos and incident response training.

The panel is divided into five independent sections:

Section 0
Core Chaos Engine
Section 1
Page Load Performance
Section 2
Functionality Failures
Section 3
Component-Level Chaos
Section 4
A/B Test Chaos

Each section has its own master toggle. You can activate any combination at the same time. Sections 1–4 work independently of the Core Chaos Engine.

Section 4 — A/B Test Chaos
Mutates DOM identifiers without visual change
This is the most subtle chaos type. Pages look identical to users, but internal DOM element IDs, form names, button identifiers, and CSS classes are mutated. This breaks Synthetic monitors that rely on specific selectors, and analytics events fire with wrong labels.
SettingWhat It MutatesWhat Breaks

Auto Chaos Mode
Continuous automated chaos loop

Continuous Loop: Auto Chaos cycles through all 5 chaos types (Named Outage, Page Load, Functionality, Component, A/B Test) in a random order. After each cycle completes, a new cycle begins with freshly shuffled order. Runs 24/7 until disabled.

Event Duration: Each event runs for 30 or 60 minutes (randomly chosen).

Cooling Gap: A mandatory 3-hour gap (plus 0–30 min jitter) between events. Gives monitoring time to show recovery before next chaos.

Daily Reshuffle: At 05:35 IST (00:05 UTC) the entire schedule rebuilds with new random order and timing.

View Schedule: Visit the Auto Chaos Dashboard to see the full timeline with countdown timers.

Quick Tips
✓
Sections are independent — Page Load chaos works without Core Chaos, and vice versa.
✓
Save after every change — Click "Save All Chaos Settings" at the bottom after toggling any setting.
✓
Named Profiles auto-enable — Clicking a profile turns on Core Chaos and sets the knobs automatically.
✓
"End All Chaos" — Resets ALL knobs in ALL sections to zero/off instantly.
✓
Target specific pages — Page Load delay only applies to selected pages; others load normally.
✓
JS injections are global — Console errors, resource failures, memory pressure apply to ALL pages when enabled.
Troubleshooting
!
Chaos not firing? — Visit /admin/chaos/debug for a diagnostic report showing exactly why chaos may not be triggering.
!
Code changes not reflecting? — Run bash snaptravels.sh restart to pick up Python file changes.
!
Auto Chaos schedule empty? — Toggle Auto Chaos OFF then ON again to force a fresh schedule rebuild.
i
State API — /admin/chaos/state.json returns all chaos state as JSON (unauthenticated, for REST API monitors).
